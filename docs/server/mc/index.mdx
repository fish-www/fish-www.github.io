## server

仓库地址：[mc-server](https://github.com/fish-www/mc-server)

使用 systemd + tmux 管理，为了能够使用 bot 插件，在 mc server 外面包了一层 mcdr

## client

仓库地址：[mc-client](https://github.com/fish-www/mc-client)

为了方便客户端更新，使用 HMCL 的服务端自动更新整合包

## bot

仓库地址：

- [BotServer](https://github.com/fish-www/BotServer)（fork 自 [Minecraft-QQBot/BotServer](https://github.com/Minecraft-QQBot/BotServer)）
- [Plugin.McdReforged](https://github.com/Minecraft-QQBot/Plugin.McdReforged)（mcdr 插件）

主要是 QQ 群聊与服务器消息互通
